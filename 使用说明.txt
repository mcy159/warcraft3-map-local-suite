魔兽争霸联机优化补丁 - 使用说明
=================================

一、包内容
  bin\                魔兽争霸增强运行库 (YDWE 完整环境: YDWEConfig / ydbase / d3d8proxy /
                     LuaEngine / SlkLib / StormLib / CJassHelper / worldedit.exe 等)
  plugin\warcraft3\   JAPI 插件集 (dzclient_api / yd_jass_api / yd_lua_engine /
                     yd_size_limit / yd_virtual_mpq 等 9 插件, 由 config.cfg 控制开关)
  version127a\        1.27a (1.27.0.52240) 完整可执行集: War3.exe / worldedit.exe /
                     Storm.dll / Mss32.dll / redist\miles 音视频依赖 (覆盖到游戏根目录用)
  Game_patched2.dll   大图补丁版 Game.dll (地图大小限制 8MB -> 1GB)
                     MD5: 690a546c9567c598262518e830286cc3
                     原版 MD5: 267861A0DFD416DBAD13E7EE3EC7794A
  maps\               放置平台图 (.w3x) 的目录
  tools\              改键/调视距工具 (SuWar3Tools 官方原版 + WarKey2017b, 部署后由
                     war3.bat 自动启动 SuWar3Tools)
  core2.exe           部署向导 (双击运行, 选游戏目录一键部署 + 升级覆盖)

二、前提
  * 纯净版 魔兽争霸3 冰封王座 1.27 (1.27.0.52240)
    - 其他版本 Game.dll 字节不同, 补丁会失效 (部署向导会自动检测 MD5 并处理)
  * 没有游戏目录? 把 version127a\ 里的文件复制成一个新目录, 即是完整 1.27a 客户端
  * 部署前请关闭正在运行的魔兽
  * 游戏目录请放在浅路径 (如 E:\War3、D:\Game), 深层路径 YDWEConfig 无法启动

三、部署步骤 (部署向导 core2.exe)
  1. 解压本包到任意目录, 双击 core2.exe
  2. 选择游戏目录 (或把游戏文件夹拖到窗口), 点击【开始部署】
  3. 向导自动完成 (进度条):
     a. 校验目录 (必须有 War3.exe 和 Game.dll)
     b. 解压内置数据包到系统临时目录
     c. 复制 bin\ + plugin\ + version127a\ + tools\ 到游戏目录 (已存在则覆盖)
     d. 复制 Game_patched2.dll + 新版 war3.bat (单工具版启动器)
     e. Game.dll 版本检测:
        - 1.27a 原版 (MD5 267861A0...) -> 备份 Game.dll.bak, 打大图补丁 (8MB -> 1GB)
        - 已补丁版 (MD5 690A546C...) -> 跳过
        - 其他旧版本 (1.20e~1.27b) -> 备份 Game.dll.ver127bak, 自动转换到 1.27a 再打补丁
     f. 自动清理临时目录
  4. 把要玩的平台图 (.w3x, 如西方世界的劫难7 约258MB 大图) 放进游戏目录
     Maps\Download\ (或放到本包 maps\ 再手动复制)
  5. 部署完成后双击游戏目录下的 war3.bat 启动游戏

  升级覆盖: 朋友电脑已部署过旧版时, 重跑一次部署向导即可自动升级 -
     新版 war3.bat 覆盖旧版 + 补齐 tools\ 工具 + 按 MD5 更新 Game.dll, 无需重下魔兽。

四、启动游戏 (war3.bat)
  游戏目录下 war3.bat 内容 (部署时自动生成/覆盖):
    @echo off
    cd /d %~dp0
    for /f "delims=" %%f in ('dir /b "tools\SuWar3Tools\*.exe" 2^>nul') do (
        start "" "tools\SuWar3Tools\%%f" & goto :tool_ok)
    :tool_ok
    bin\YDWEConfig.exe -launchwar3

  作用: 自动先启动 SuWar3Tools 改键/调视距工具 (后台常驻) -> 再启动游戏。
  * 必须用 war3.bat 启动! 直接双击 War3.exe 插件不生效, 进图会弹回主菜单。

五、改键 / 视距 / 菜单 操作 (SuWar3Tools)
  * 工具随 war3.bat 自动启动, 无需手动运行

  1. 技能改键 (预配 QWER, 需游戏内校准一次):
     - 软件已预配: CusSkill1-4 = Q/W/E/R
     - 校准方法: 开启技能改键后, 把鼠标放到技能栏【第一格】中心,
       按 Ctrl+Alt+左键 记录; 再放到【最后一格】中心, 按 Ctrl+Alt+左键 记录
       (软件自动算出 12 格坐标)
     - 之后按 Q / W / E / R 点击格子即可放技能, 全图通用
  2. 视距调整:
     - 小键盘【0】拉高视野, 小键盘【.】(小数点) 拉低视野
     - 注意: 小键盘需要 NumLock 灯亮
  3. 改键菜单:
     - 游戏内按【F7】呼出 SuWar3Tools 改键/调视距菜单 (Menu.KeyPress=118)
     - 不是 Alt+Esc! 那是 Windows 系统切换窗口的键, 游戏内按会切出游戏
  4. 方案切换热键已禁用 (KeyPlanLast/KeyPlanNext=0), 用菜单内点击切换即可

六、配合解锁注入器 (地图解锁版玩法)
  1. 环境对接: 本包部署完成后, 游戏目录已具备 bin\YDWEConfig.exe 与 plugin\warcraft3\,
     解锁注入器注入完成后会自动检测这两项并提示"环境就绪"。
  2. 选图解锁: 双击桌面「魔兽地图解锁注入器.exe」-> 选择地图 (或关联地图文件夹,
     自动递归扫描子目录所有 .w3x/.w3m) -> 勾选要解锁的功能 (商城/等级/存档等) ->
     点【开始注入】-> 解锁版图输出在 所选图/关联目录 下新建的 xgt\ 文件夹。
  3. 放图启动: 把 xgt\ 里的解锁版图复制到 游戏目录\Maps\Download\,
     双击游戏目录 war3.bat 启动 -> 自定义游戏 -> 选择图 -> 创建 -> 开始。
  4. 一键流程: 部署环境 (core2.exe) -> 选图解锁 (注入器) -> 放图启动 (war3.bat)。

七、注意事项
  * 杀毒软件可能拦截 war3.bat / SuWar3Tools (程序有加密, 误报属正常), 请添加白名单
  * 卸载: 删除游戏目录下 bin\ plugin\ war3.bat, Game.dll 用 Game.dll.bak 还原
  * 本工具仅供离线单机游玩平台图/学习交流使用, 请支持正版

八、多魔兽共存
  * 本包支持多份魔兽安装共存：从哪个目录双击 war3.bat 启动，就玩哪个目录的魔兽。
  * war3.bat 启动时会自动把注册表 InstallPath 指向当前游戏目录（HKCU + HKLM\WOW6432Node 各一条），YDWEConfig 按注册表定位游戏，不会再串到别的安装。
  * 前提：每份魔兽都要各自部署过本包（bin/plugin/version127a/tools/Game.dll 补丁），直接复制部署好的整个游戏目录即可。
